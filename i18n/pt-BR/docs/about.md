# Sobre

## Finalidade
Este repositório e seu site ensinam como as linguagens de programação
diferem, mostrando um programa pequeno, o Hello World, escrito em cada uma
delas. Toda implementação é completa e executável: acompanha scripts que
instalam a toolchain, compilam o programa e o executam, e cada script explica
cada etapa enquanto é executado.

Cada linguagem também tem uma página com sua
história, seus marcos e seu lugar na indústria atual, e todo fato dessas
páginas cita uma fonte (consulte [Sobre as fontes](sources.md)).

## Público-alvo
O material é escrito para estudantes e profissionais de todas as áreas da
tecnologia da informação (TI) e para qualquer pessoa curiosa sobre
linguagens de programação. Não se
pressupõe conhecimento prévio de nenhuma linguagem em particular. Quem conhece
uma linguagem pode usar as demais implementações para ver quais ideias são
compartilhadas e quais são particulares de cada linguagem; a página
[Comece aqui](start-here.md) sugere uma ordem de leitura.

## Como citar
O repositório inclui um arquivo [`CITATION.cff`](../CITATION.cff) no
[Citation File Format](https://citation-file-format.github.io/). O GitHub o
lê e oferece versões em APA e BibTeX em *Cite this repository*. Uma citação em
texto simples:

> Hamerski, E. (2026). *Hello World in many programming languages*
> [Computer software and teaching material].

Acrescente o endereço do repositório, ou da página citada, e a data de
acesso.
