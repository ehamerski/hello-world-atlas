# Hello World em várias linguagens de programação

## O que é este site
Este site mostra um programa pequeno, o Hello World, escrito em várias
linguagens de programação. Cada linguagem o escreve da forma mais simples e
direta: como programa de linha de comando, janela desktop, aplicação web
ou, em algumas linguagens, aplicativo mobile.

Cada linguagem também tem uma página com sua história, seus marcos e seu
uso atual. Todo fato dessas páginas cita uma fonte.

## Três pontos de partida
- **[Comece aqui](start-here.md)** para executar um exemplo. A página mostra
  como obter um terminal que executa os scripts e o que cada script faz.
- **[Linguagens](../languages/README.md)** para procurar uma linguagem.
  Busque-a pelo nome, ordene a lista por ano ou filtre-a por paradigma e
  plataforma.
- **[Comparar](comparisons.md)** para ver as diferenças. Leia os programas
  lado a lado, com suas etapas de compilação e seus tamanhos medidos.

## Como funciona
Cada exemplo é uma pasta com seu código e três scripts: `install.sh`
verifica as ferramentas, `build.sh` compila o programa quando a linguagem
exige e `run.sh` o executa. Durante a execução, cada script informa o que
faz e por quê, e pede confirmação antes de instalar qualquer coisa.

Cada exemplo pode ser baixado como arquivo ZIP na página da sua linguagem.
As páginas deste site são construídas a partir dos mesmos arquivos; assim,
o código lido aqui é o código que é executado.
