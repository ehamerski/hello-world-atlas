# Hello World in many programming languages

## What this site is
This site shows one small program, Hello World, written in many
programming languages. Each language writes it in the simplest and most
direct way: as a command-line program, a desktop window, a web application
or, for a few languages, a mobile app.

Every language also has a page with its history, its milestones and its
use today. Every fact on those pages cites a source.

## Three ways in
- **[Start here](start-here.md)** if you want to run an example. It shows
  how to get a terminal that runs the scripts, and what each script does.
- **[Languages](../languages/README.md)** if you look for one language. Find
  it by name, sort the list by year, or filter it by paradigm and platform.
- **[Compare](comparisons.md)** if you want to see the differences. Read the
  programs side by side, with their build steps and measured sizes.

## How it works
Each example is a folder with its code and three scripts: `install.sh`
checks the tools, `build.sh` compiles the program when the language needs
it, and `run.sh` runs it. Each script says what it does and why while it
runs, and it asks before it installs anything.

Each example can be downloaded as a ZIP file from its language page. The
pages of this site are built from the same files, so the code you read here
is the code that runs.
