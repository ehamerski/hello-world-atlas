# About

## Purpose
This repository and its website teach how programming languages differ by
showing one small program, Hello World, written in each of them. Every
implementation is complete and runnable: it comes with scripts that install
the toolchain, build the program and run it, and every script explains each
step as it runs.

Each language also has a page with its history, its
milestones and its place in the industry today, and every fact on those
pages cites a source (see [About the sources](sources.md)).

## Audience
The material is written for students and professionals in every area of
information technology (IT), and for anyone who is curious about
programming languages. No previous
knowledge of any particular language is assumed. A reader who knows one
language can use the other implementations to see which ideas are shared
and which are particular to a language; [Start here](start-here.md)
suggests a reading order.

## How to cite
The repository includes a [`CITATION.cff`](../CITATION.cff) file in the
[Citation File Format](https://citation-file-format.github.io/). GitHub
reads it and offers APA and BibTeX versions under *Cite this repository*.
A plain-text citation:

> Hamerski, E. (2026). *Hello World in many programming languages*
> [Computer software and teaching material].

Add the address of the repository, or of the page you are citing, and the
date you accessed it.
